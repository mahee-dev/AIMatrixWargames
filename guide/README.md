# AMAW guides

These pages describe how to use the current source-checkout release:

- [Field Manual](manual.html): an illustrated tour of how a game plays, how adjudication works,
  which settings change what, and how repeated runs become a benchmark. Open it in a browser.
- [Install, configure, run, and export a game](operations.md)
- [Author a scenario](scenario-authoring.md)
- [Contribute to AMAW](../CONTRIBUTING.md)

For the game loop and player/Umpire rules, use the normative
[`state-machine.md`](../docs/state-machine.md) and [`agents.md`](../docs/agents.md). For the exact
HTTP interface, use [`api.md`](../docs/api.md). The complete specification index and precedence
rules are in [`docs/README.md`](../docs/README.md).

These guides are non-normative. They aim to make the released engine usable without
restating every contract. If a guide and a contract disagree, the contract wins.
