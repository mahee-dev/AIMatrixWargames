# The original vision

The three planning documents AMAW was built from, kept as they stood at the start of the project
(2026-09-10). They show what the platform was meant to be before any code existed.

| File | What it is |
|---|---|
| `AMAW_PRD_v0.4.1.md` | Product Requirements: why AMAW exists, the Matrix Game method, the MVP and its non-goals |
| `AMAW_TRD_v0.5.1_Lean_MVP.md` | Technical Requirements as first written (v0.5.1, from commit `8c4571a`) |
| `AMAW_WBS_v0.2.1.md` | The delivery Work Breakdown Structure (content v0.2.2): the 66 steps, delivery gates (§8), critical path (§9), out-of-scope list (§7) and Phase-2 plan (§11) |
| `UPDATE_SUMMARY.md` | The 2026-09-10 note reconciling the first documentation pack |

The living PRD and TRD are `docs/PRD.md` and `docs/TRD.md`; the plan and progress record is
`dev/WBS.md`. Where the delivery WBS and `AGENTS.md` disagree, `AGENTS.md` wins: benchmarking
became a post-MVP milestone after this WBS was written, so its Gate 4 is no longer an MVP gate.
These files are history. Do not edit them.
